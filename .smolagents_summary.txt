║                              QUICK START (3 STEPS)                             ║
╚═══════════════════════════════════════════════════════════════════════════════╝

  1. Install:     pip install "smolagents[toolkit]>=1.0.0"

  2. Run:         python main_smolagents.py \
                    --problem_name oscillator1 \
                    --spec_path specs/specification_oscillator1_numpy.txt

  3. Monitor:     tensorboard --logdir logs/oscillator1_smolagents

  OR: Use interactive script → bash run_smolagents.sh

    • 100+ other providers

  HuggingFace Inference API (via InferenceClientModel):
    • Any model on HF with Inference API enabled

╔═══════════════════════════════════════════════════════════════════════════════╗
║                            TROUBLESHOOTING QUICK                               ║
╚═══════════════════════════════════════════════════════════════════════════════╝

  "Module smolagents not found"
    → pip install "smolagents[toolkit]>=1.0.0"

  CUDA out of memory
    → Use smaller model: --local_model_id Qwen/Qwen2.5-Coder-7B-Instruct

  API key errors
    → Check: echo $OPENAI_API_KEY
    → Check: echo $GEMINI_API_KEY

  See full troubleshooting: QUICKSTART_SMOLAGENTS.md → Section "Troubleshooting"
