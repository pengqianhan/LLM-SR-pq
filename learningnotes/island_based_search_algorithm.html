基于岛屿的搜索算法 | Island-Based Search Algorithm

LLM符号回归中的多种群进化策略 | Multi-Population Evolution Strategy in LLM Symbolic Regression
概述 | Overview

🏝️ 什么是基于岛屿的搜索算法？

基于岛屿的搜索算法是一种多种群进化算法，将整个搜索空间划分为多个独立的"岛屿"。每个岛屿维护自己的候选解群体，独立进化，同时通过迁移机制保持岛屿间的信息交流。

🏝️ What is Island-Based Search Algorithm?

Island-based search algorithm is a multi-population evolutionary algorithm that divides the entire search space into multiple independent "islands". Each island maintains its own population of candidate solutions, evolves independently, while maintaining information exchange between islands through migration mechanisms.

🎯 在LLM-SR系统中的应用

在LLM符号回归系统中，每个岛屿存储不同的数学方程变体。系统从共同的specification开始，然后各岛屿独立探索不同的方程形式，避免过早收敛到局部最优解。

🎯 Application in LLM-SR System

In the LLM Symbolic Regression system, each island stores different mathematical equation variants. The system starts from a common specification, then each island independently explores different equation forms, avoiding premature convergence to local optima.

🧩 聚类机制

每个岛屿内部使用聚类系统，将具有相似性能的方程归为一组：

🧩 Clustering Mechanism

Each island uses an internal clustering system to group equations with similar performance:

# /llmsr/buffer.py - Island class class Island: def __init__(self, ...): # 🧬 按性能签名分组的聚类系统 | Clustering system grouped by performance signature self._clusters: dict[Signature, Cluster] = {} self._num_programs: int = 0 def register_program(self, program, scores_per_test): # 🔍 计算性能签名 | Calculate performance signature signature = _get_signature(scores_per_test) if signature not in self._clusters: # 🆕 创建新聚类 | Create new cluster score = _reduce_score(scores_per_test) self._clusters[signature] = Cluster(score, program) else: # 📝 添加到现有聚类 | Add to existing cluster self._clusters[signature].register_program(program)

📊 性能签名系统

系统根据方程在不同测试数据上的表现计算唯一的性能签名，相同签名的方程被归为一类。

📊 Performance Signature System

The system calculates unique performance signatures based on equation performance on different test data, grouping equations with the same signature.

def _get_signature(scores_per_test: ScoresPerTest) -> Signature: # 将测试分数转换为规范化签名 | Convert test scores to canonical signature return tuple(scores_per_test[k] for k in sorted(scores_per_test.keys())) # 示例 | Example: # 方程A在3个测试上的分数: [0.85, 0.92, 0.78] → 签名: (0.78, 0.85, 0.92) # 方程B在3个测试上的分数: [0.85, 0.92, 0.78] → 签名: (0.78, 0.85, 0.92) [同一聚类]
岛屿重置机制 | Island Reset Mechanism

🔄 定期重置策略

系统每4小时执行一次岛屿重置，淘汰表现最差的一半岛屿，并从优秀岛屿中引入基因重新初始化。

🔄 Periodic Reset Strategy

The system performs island reset every 4 hours, eliminating the worst-performing half of islands and reinitializing with genes from excellent islands.

📊 性能排序

根据各岛屿的最佳分数对所有岛屿进行排序，添加随机噪声打破平局。

📊 Performance Ranking

Sort all islands based on their best scores, adding random noise to break ties.

算法优势 | Algorithm Advantages

🎯 避免过早收敛

多个岛屿独立进化，即使某些岛屿陷入局部最优，其他岛屿仍能继续探索，大大降低了算法过早收敛的风险。

🎯 Avoid Premature Convergence

Multiple islands evolve independently. Even if some islands fall into local optima, others can continue exploring, greatly reducing the risk of premature convergence.

🌈 保持种群多样性

岛屿间的隔离机制确保了搜索空间的多样性，每个岛屿可以专注于不同的数学形式，从线性到非线性，从简单到复杂。

🌈 Maintain Population Diversity

The isolation mechanism between islands ensures diversity in the search space, allowing each island to focus on different mathematical forms, from linear to nonlinear, from simple to complex.

⚖️ 平衡探索与利用

系统通过随机岛屿选择实现探索，通过聚类内的最优采样实现利用，在全局搜索和局部优化之间找到了良好平衡。

⚖️ Balance Exploration and Exploitation

The system achieves exploration through random island selection and exploitation through optimal sampling within clusters, finding a good balance between global search and local optimization.

🔄 自适应重置机制

定期的岛屿重置机制确保算法能够跳出局部最优，同时通过基因迁移保留优秀的搜索经验。

🔄 Adaptive Reset Mechanism

The periodic island reset mechanism ensures the algorithm can escape local optima while preserving excellent search experience through gene migration.

🚀 并行化潜力

岛屿间的独立性使得算法天然适合并行化实现，可以在多台机器上同时运行不同的岛屿，大幅提升搜索效率。

🚀 Parallelization Potential

The independence between islands makes the algorithm naturally suitable for parallel implementation, allowing different islands to run simultaneously on multiple machines, greatly improving search efficiency.

总结 | Summary

🎯 核心思想

基于岛屿的搜索算法通过将搜索空间划分为多个独立进化的子空间，有效解决了单一种群进化算法容易陷入局部最优的问题。在LLM符号回归系统中，这种方法特别适合探索复杂的数学表达式空间。

🎯 Core Idea

Island-based search algorithm effectively solves the problem of single-population evolutionary algorithms easily falling into local optima by dividing the search space into multiple independently evolving subspaces. In LLM symbolic regression systems, this method is particularly suitable for exploring complex mathematical expression spaces.

🔑 关键机制

  • 统一初始化：所有岛屿从相同的specification开始
  • 独立进化：每个岛屿根据随机采样独立发展
  • 聚类管理：岛屿内部按性能签名分组管理
  • 定期重置：淘汰弱岛屿，引入优秀基因
  • 多样性保持：通过隔离和迁移平衡多样性与收敛性

🔑 Key Mechanisms

  • Unified Initialization: All islands start from the same specification
  • Independent Evolution: Each island develops independently based on random sampling
  • Cluster Management: Internal grouping by performance signatures within islands
  • Periodic Reset: Eliminate weak islands and introduce excellent genes
  • Diversity Maintenance: Balance diversity and convergence through isolation and migration

✨ 实际效果

这种多岛屿架构使得LLM符号回归系统能够同时探索多种数学形式，从简单的线性组合到复杂的非线性函数，大大提高了发现最优数学表达式的概率，是一种兼具理论基础和实用价值的优秀算法设计。

✨ Practical Effects

This multi-island architecture enables the LLM symbolic regression system to simultaneously explore various mathematical forms, from simple linear combinations to complex nonlinear functions, greatly improving the probability of discovering optimal mathematical expressions. It is an excellent algorithm design with both theoretical foundation and practical value.
